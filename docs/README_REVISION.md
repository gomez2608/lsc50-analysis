# Revision register (PLOS One PONE-D-26-34021)

| Document | What it holds |
|----------|---------------|
| `RESULTS_SUMMARY.md` | Current headline numbers in one place. |
| `POSE_TRANSFORMER_STUDY.md` | Protocol of the pose transformer robustness study (questions a reviewer may ask, the study for each), fixed before running. |
| `SEQUENCE_IMPORTANCE.md` | Protocol of the permutation importance for the pose transformer and ST-GCN (extends §5.14 to sequence models; finger-level amendment 2026-10-26), fixed before running. |
| `METHODS_REVISION.md` | Each method exactly as implemented, with script and commit; basis for the paper's Methods. |
| `HYPERPARAMETERS.md` | Grids, selected settings, ViViT and linear-probe configurations (R2.11). |
| `DATA_MANIFEST.md` | Every data and result file (Mac and server) with size and MD5; raw archives checked against figshare. |
| `results/` | Result tables (CSV), signer-level CIs (`signer_ci.csv`), DTW tables (`dtw/`), ViViT `results.json` and learning curves (`vivit/`), pose-transformer runs and controls (`pose/`, `pose_control/`), audit outputs (`audit/`). |
| `figures/` | Figures (PNG), regenerated by `scripts/revision/make_figures.py`; the landmark reconstructions by `scripts/revision/landmark_figures/`. |
| `requirements-revision-lock*.txt` | Exact package lists (Mac, server, SlowFast and SPOTER environments). |

Code for the revision: `scripts/revision/` (runs and analyses) and `scripts/revision/audit/` (checks on the original workspace).


The authors' internal working notes (chronological revision log, planning and correspondence notes) are not part of this repository. References in these documents to `REVISION_LOG` sections, and to comment labels such as R2.11, point to those notes; the results they refer to are in `results/`, and the analyses are described in the paper and its Supporting Information.
